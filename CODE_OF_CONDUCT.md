# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment,
discrimination, and personal attacks are not tolerated in any project space.

Given the forensic nature of this project, one additional rule applies:
**never share real case data** (chat content, personal data, media from real devices)
in issues, discussions, pull requests, or any other project channel.

Report violations privately to the maintainers via GitHub. Reports are handled
confidentially.
