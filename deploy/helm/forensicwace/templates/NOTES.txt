{{- if .Values.worker.keda.enabled }}
Worker autoscaling: KEDA scales {{ include "fw.fullname" . }}-worker between
{{ .Values.worker.keda.minReplicas }} and {{ .Values.worker.keda.maxReplicas }} replicas on the depth of the
media/text queues (target {{ .Values.worker.keda.queueLength }} msgs/replica).
Watch it live during an analysis:
  kubectl -n {{ .Release.Namespace }} get hpa,scaledobject,pods -w
{{- else }}
NOTE: worker.keda.enabled=false — workers run at a fixed {{ .Values.worker.replicas }} replicas.
Install KEDA (https://keda.sh/docs/latest/deploy/) and set worker.keda.enabled=true
to autoscale on queue depth.
{{- end }}
